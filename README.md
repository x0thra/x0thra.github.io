## Directories

**__Root (/):__** All files are under here. Though you will realize that the ls output will show a lot of directories in red color. This means you can't cd into it or read/see anything inside. I'm not coding the whole Linux file system..<br><br>
**__/home:__** This is where user files are stored (including my files for other people to check out). The directory "x0thra" contains my files, and "guest" contains the current visitor's (which is you) files. And yeah you can create text files and they will be stored there. Don't worry, they wil be only available on your browser and not other people's. They will be saved in your browser's local storage. So you can just my website as a notepad I guess..
